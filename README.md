# BMSIT&M — Engineer Your Future

A one-page React experience for BMS Institute of Technology and Management. Built with Vite, Tailwind CSS, Framer Motion and Lucide.

## Run locally

Install [Node.js](https://nodejs.org/) 22.12 or newer (or 20.19 or newer), then open a terminal in this folder:

```powershell
npm install
npm run dev
```

Open the local address printed by Vite. To create and preview a production build:

```powershell
npm run build
npm run preview
```

## Content and imagery

The original authoring workspace used campus photography from image paths published on the official [BMSIT&M website](https://bmsit.ac.in/). Those photographs are not included in this repository because redistribution permission was not verified. The app falls back to `public/images/image-placeholder.svg` when an image is unavailable. Add institution-approved photographs only after confirming permission to publish them.

The academics section links to official programme and admissions information instead of publishing an unverified programme list. Sample event cards, story spaces, and the campus-discovery graphic are clearly identified as placeholders. The contact details and address are sourced from the [official contact information](https://bmsit.ac.in/contact-details.php).

The contact form provides native browser validation but does not submit, transmit, or store personal information. Configure an approved backend before using it for real enquiries.
